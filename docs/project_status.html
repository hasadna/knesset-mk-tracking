Project Status & Parliamentary Processing

Technical report on the system architecture, Gemini-powered opinion synthesis, and end-to-end legislative bill data processing pipelines.

📊
Deployed Infrastructure
Deployed on Google Cloud BigQuery (Dataset mk_tracking). Uses a React 19 + Vite frontend backed by FastAPI reading directly from BigQuery.
🤖
Gemini Embedding & Gating
Every social post is embedded with gemini-embedding-2 (3,072 dims). K-means ($K=30$) filters out non-political noise before scoring against 7 core issues.
🏛️
Knesset Open Data
Ingests MKs, party affiliations, proposed/enacted bills, vote events, and individual voting records directly from Open Knesset APIs.
❌ Question Answered
Are bills taken into account in the opinion summaries?
No, opinion summaries currently rely EXCLUSIVELY on social media (X/Twitter) posts.

The summary generation pipeline (BigQuerySource.load_inputs()) passes top Twitter posts to Gemini. The model's strict system prompt explicitly forbids using external sources or parliamentary data when generating stances:
"אתה מנתח ראיות פוליטיות בעברית. מותר להסיק אך ורק מהציוצים שסופקו."
💬 "What They Said" (Social Stance)
Generated inside mk_issue_summary. Derived purely from social media posts to reflect public statements and rhetoric.
🗳️ "What They Did" (Parliamentary Record)
Tracked via bill, bill_issue, and mk_vote. Aggregated in SQL views like v_said_vs_did to compare votes against rhetoric.

Key Database Tables for Legislative Bills
Database schema specifications in BigQuery dataset mk_tracking.
Table Name Natural Key Primary Content & Role Mapping / AI Processing
mk_tracking.bill knesset_bill_id Stores scraped bill titles, Hebrew summaries, status, and GCS document URIs. Raw source data ingested from Open Knesset API.
mk_tracking.bill_issue (bill_id, issue_id) Junction table connecting bills to policy issues with mapping notes. Populated by gemini-3.6-flash with confidence score & Hebrew rationale.
mk_tracking.bill_author (bill_id, mk_id) Links MKs to bills they initiated or co-sponsored. Used in v_mk_issue_authorship view for legislative initiative counts.
mk_tracking.vote_event external_key Covers plenum readings and committee motions related to bills. Joined with mk_vote to measure parliamentary voting history per issue.
